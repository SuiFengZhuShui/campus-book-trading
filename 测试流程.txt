校园二手书 — 使用说明与测试流程
============================

────

一、学生正常使用流程
─────────────────────

1. 首页浏览
   打开 http://127.0.0.1/
   - 看到 Hero Banner "校园二手教材交易平台"
   - 看到下方滚动提示字幕
   - 看到书籍网格（每本有封面、书名、作者、成色、价格）
   - 看到"立即购买"按钮

2. 学院筛选
   - 导航栏下拉框选学院（如"电子信息工程学院"）
   - 列表只显示该学院的书

3. 搜索 + 排序
   - 搜索框输入关键词 → 回车
   - 搜索结果页可切换排序：最新 / 价格升 / 价格降 / 成色优先

4. 注册 → 登录
   点击右上角"登录" → 底部"还没有账号？立即注册"
   - 填写姓名、手机号、密码 → 注册成功跳转登录页
   - 输入手机号 + 密码 → 登录后回到首页
   - 导航栏右侧显示用户名、"我的订单"、"我的卖书"

5. 书籍详情
   点击任意书籍卡片 → /books/{id}
   - 封面大图
   - 书名、作者、出版社、成色、售价、原价
   - "立即购买"按钮

6. 直接购买（无购物车）
   点击"立即购买" → /buy/{bookId}
   - 确认订单信息
   - 选择取书地点
   - 提交订单 → 跳转订单详情页

7. 我的订单
   导航栏"我的订单" → /orders
   - 订单列表（待付款/已付款/已确认/已取书）
   - 点击进入订单详情 → 可支付/取消

8. 卖书
   导航栏"卖书" → /sell
   - 填写书名、作者、出版社、学院
   - 选择成色、上传图片（2-5 张）
   - 提交 → 等待管理员审核定价

9. 我的卖书
   导航栏"我的卖书" → /my-sells
   - 查看已提交的卖书列表
   - 已售出的书可点"查看订单"

10. 求购广场
    导航栏"求购" → /wants
    - 浏览其他同学的求购信息
    - 点击进入求购详情

11. 求购详情 → 卖书预填
    求购详情页点"我要卖这本书" → /sell
    - 书名、作者、出版社、学院自动预填
    - 补充成色、上传图片后提交

12. 发布求购
    求购广场右上角"发布求购" → /post-want
    - 填写书名、作者、出版社、学院、最高价、可接受成色
    - 如该书已有在售 → 黄色提示"该书已有用户在售（¥XX），可前往书籍详情直接购买"
    - 提交成功 → 跳转求购广场
