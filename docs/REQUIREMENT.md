# 校园二手书交易平台 — 需求文档

## 项目定位

面向校内学生的二手书交易平台，**平台自营模式**。学生将闲置书卖给平台，平台统一拍照、定价、上架，买家在线下单支付后线下取书。

## 用户角色

| 角色 | 注册方式 | 登录方式 | 权限 |
|------|---------|---------|------|
| 学生用户 | 学号注册 | 手机号 + 密码 | 浏览、下单、评价、求购 |
| 平台管理员 | 后台创建 | 用户名 + 密码 | 收书、定价、上架、发货、管理 |

## 书籍分类

| 一级分类 | 说明 |
|---------|------|
| 教材教辅 | 各专业课程教材、辅导书、习题集 |
| 考研考公 | 考研、考公、考证类书籍 |
| 文学小说 | 中外文学、小说、散文、诗歌 |
| 杂志漫画 | 期刊杂志、漫画、绘本 |
| 其他 | 不属于以上分类的书籍 |

每本书可选关联：学院 → 专业 → 课程。

## 成色标准

| 成色 | 判断标准 | 售价比例 |
|------|---------|---------|
| 全新 | 无使用痕迹，无折痕无笔记 | 原价 70%-80% |
| 几乎全新 | 有轻微翻阅痕迹，无笔记 | 原价 55%-70% |
| 正常使用 | 有笔记、折痕，不影响阅读 | 原价 35%-55% |
| 较旧 | 明显使用痕迹，笔记较多 | 原价 20%-35% |

## 定价规则

- 同一本书（同书名+同作者+同出版社）统一基础定价
- 不同成色按比例浮动，形成价格区间
- 系统根据书名自动建议价格，管理员可手动调整
- 平台收书价格为售价的 40%-60%

## 核心流程

### 卖书
学生联系平台 → 管理员线下收书（检查成色/拍照/协商收书价）→ 平台统一上架

### 买书
浏览/搜索 → 加入购物车 → 提交订单 → 模拟支付 → 管理员确认 → 线下取书 → 确认取书 → 评价 → 完成

### 订单状态

| 状态 | 操作角色 |
|------|---------|
| 待付款 | 买家：支付/取消 |
| 已付款 | 管理员：确认 |
| 已确认 | 买家：确认取书 |
| 已取书 | 买家：评价 |
| 已完成 | — |
| 已取消 | — |

超时：待付款 30 分钟自动取消；已付款 48 小时自动取消并退款。

## 求购广场

- 买家发布求购（书名/作者/出版社/成色/最高价）
- 有书者接单 → 走正常卖平台流程 → 标注「已有货」
- 求购有效期 7 天

## 评价系统

- 买家单向评价（平台为卖家）
- 维度：书况（1-5 星）、服务（1-5 星）、文字评价（选填）
- 信用展示：好评率、累计售出数量

## 图片管理

- 每本书至少 3 张（封面/内页/书脊），最多 9 张
- 管理员统一拍摄、裁剪、上传

## 平台形态

- Web 端：管理员后台 + 学生前台
- 移动端：uni-app 跨平台，面向学生用户
- 不需要站内聊天（IM）
