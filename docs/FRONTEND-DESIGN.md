### 2.2 路由配置

```js
// router/index.js
const routes = [
  { path: '/login', component: Login, meta: { guest: true } },
  { path: '/register', component: Register, meta: { guest: true } },
  {
    path: '/',
    component: MainLayout,       // 公共布局：header + 内容区 + footer
    children: [
      { path: '', name: 'home', component: Home },
      { path: 'books/:id', name: 'book-detail', component: BookDetail },
      { path: 'cart', name: 'cart', component: Cart, meta: { auth: true } },
      { path: 'checkout', name: 'checkout', component: Checkout, meta: { auth: true } },
      { path: 'orders', name: 'orders', component: Orders, meta: { auth: true } },
      { path: 'orders/:id', name: 'order-detail', component: OrderDetail, meta: { auth: true } },
      { path: 'my-books', name: 'my-books', component: MyBooks, meta: { auth: true } },
      { path: 'submit-book', name: 'submit-book', component: SubmitBook, meta: { auth: true } },
      { path: 'wants', name: 'wants', component: Wants },
      { path: 'wants/:id', name: 'want-detail', component: WantDetail },
      { path: 'post-want', name: 'post-want', component: PostWant, meta: { auth: true } },
      { path: 'profile', name: 'profile', component: Profile, meta: { auth: true } },
    ]
  }
]
```

### 2.6 登录页 — `/login`

```
┌──────────────────────────────────────────────┐
│  Logo                         校园二手书      │
│                                              │
│          ┌─────────────────────┐             │
│          │  手机号 [________]   │             │
│          │  密码   [________]   │             │
│          │                     │             │
│          │  [      登录      ] │             │
│          │                     │             │
│          │  还没有账号？[去注册] │             │
│          └─────────────────────┘             │
└──────────────────────────────────────────────┘
```

| 字段 | 校验 |
|------|------|
| 手机号 | 必填，11 位手机号格式 |
| 密码 | 必填，≥6 位 |

| 状态 | 处理 |
|------|------|
| 登录成功 | 存 token 到 localStorage → Vuex → 跳转首页 |
| 登录失败 | 表单上方红色提示"手机号或密码错误" |
| 提交中 | 按钮禁用 + loading 文字"登录中..." |
| 未登录访问需认证页面 | 记录目标路径 → 跳转登录 → 登录成功后跳回 |

```
│          │  已有账号？[去登录]   │             │
│          └─────────────────────┘             │

```

| 字段 | 校验 |
|------|------|
| 学号 | 必填，唯一 |
| 姓名 | 必填，2-20 字 |
| 手机号 | 必填，11 位，唯一，失焦时 AJAX 查重 |

| 状态 | 处理 |
|------|------|

| 校验失败 | 对应字段下方红色提示 |
| 手机号已存在 | 失焦时 AJAX 返回 → 提示"该手机号已注册" |
| 提交中 | 按钮禁用 + "注册中..." |

**分类侧边栏交互**
- 点击分类 → 高亮选中 → 右侧书籍列表筛选刷新
- "全部"为默认选中项
- 学院/专业/课程级联下拉，作为额外筛选

**书籍卡片 BookCard**

| 元素 | 说明 |
|------|------|
| 封面图 | 第一张 cover 图，200×260px，点击跳详情 |
| 书名 | 加粗，最多 2 行截断 |
| 成色标签 | 小 Badge：全新=绿 / 几乎全新=蓝 / 正常=黄 / 较旧=灰 |
| 售价 | 绿色加粗 ¥XX.00 |
| 原价 | 灰色删除线 ¥XX.00 |

**搜索栏**
- 输入关键词 → 回车或点搜索图标 → 书籍列表按书名/作者模糊搜索
- 搜索时分类筛选保留（可叠加）
- 清空搜索框恢复默认列表

**分页**：每页 15 本，URL query 同步（`?category=1&page=2`），浏览器前进后退可用

**状态覆盖**

| 状态 | 表现 |
|------|------|
| loading | 12 个卡片骨架屏（灰色占位块） |
| empty | "暂无在售书籍" + 引导去求购广场 |
| error | "加载失败" + `[重试]` |
| success | 正常卡片网格 |

**交互规则**

| 操作 | 行为 |
|------|------|
| 勾选/取消勾选 | 单个勾选，底部合计实时更新 |
| 全选/取消全选 | 批量勾选 |
| 修改数量 | 不适用（每本书只一本，数量恒为 1） |
| 删除 | 从购物车移除，无需确认（可后续加回） |
| 去结算 | 至少选 1 件 → 跳转 checkout，传入选中的 book_ids |
| 点击书名/封面 | 跳转书籍详情 |

**购物车存储**：localStorage（未登录也可用），登录后与后端同步可留到后续

|------|------|
| empty | 购物车图标 + "购物车是空的" + `[去逛逛]` 跳首页 |

### 5.3 超时取消流

```
时间线             系统定时任务
  │                   │
  │  (每分钟执行)       │
  │                   │
  │  检查 pending 订单  │
  │  created_at > 30min │
  │  ├── Yes: 自动取消  │
  │  │  status→cancelled│
  │  │  cancelled_at    │
  │  │  cancel_reason   │
  │  │  ="超时未支付"   │
  │  │  书籍恢复 active  │
  │  │                   │
  │  检查 paid 订单      │
  │  paid_at > 48h      │
  │  ├── Yes: 自动取消  │
  │  │  status→cancelled│
  │  │  cancel_reason   │
  │  │  ="超时未确认"   │
  │  │  书籍恢复 active  │
  │  │                   │
  │  检查 wants 求购     │
  │  expires_at < now   │
  │  status=active      │
  │  ├── Yes:           │
  │  │  status→expired  │
```

**Laravel 计划任务**
```php
// app/Console/Kernel.php
$schedule->call(function () {
    // 待付款超时 30 分钟
    Order::where('status', 'pending')
        ->where('created_at', '<', now()->subMinutes(30))
        ->each(function ($order) {
            $order->status = 'cancelled';
            $order->cancelled_at = now();
            $order->cancel_reason = '超时未支付';
            $order->save();
            Book::whereIn('id', $order->items->pluck('book_id'))->update(['status' => 'active']);
        });

    // 已付款超时 48 小时
    Order::where('status', 'paid')
        ->where('paid_at', '<', now()->subHours(48))
        ->each(function ($order) {
            $order->status = 'cancelled';
            $order->cancelled_at = now();
            $order->cancel_reason = '超时未确认';
            $order->save();
            Book::whereIn('id', $order->items->pluck('book_id'))->update(['status' => 'active']);
        });

    // 求购过期
    Want::where('status', 'active')
        ->where('expires_at', '<', now())
        ->update(['status' => 'expired']);
})->everyMinute();
```

### 5.4 书籍锁定机制

**问题**：用户下单后、支付前，书籍仍为 active，可能被其他人同时下单。

**方案**：下单时锁定书籍

```
下单流程：
1. 检查所有 book_ids 是否 status='active'
2. 如果有书已非 active → 返回错误"xxx 已被他人购买"
3. 全部合法 → 创建订单 + order_items
4. 书籍不直接改 status（仍在售状态）
5. 支付成功后 → 书籍 status 保持 active（等待管理员确认）
6. 管理员确认后 → 书籍仍 active（等待买家取书）
7. 订单完成 → 书籍 status → sold

防并发：
- 数据库事务包裹步骤 1-3
- 使用 SELECT ... FOR UPDATE 锁定行
```

## 六、图片存储方案

### 6.1 存储路径规范

```
storage/app/public/
├── books/
│   └── {book_id}/
│       ├── original/         原始上传图
│       │   ├── cover_1.jpg
│       │   ├── inner_1.jpg
│       │   ├── spine_1.jpg
│       │   └── ...
│       ├── thumb/            缩略图 200×260
│       │   ├── cover_1_thumb.jpg
│       │   └── ...
│       └── medium/           中等图 600×780（详情页）
│           ├── cover_1_medium.jpg
│           └── ...
├── avatars/
│   └── {user_id}/
│       ├── avatar_thumb.jpg  80×80
│       └── avatar_medium.jpg 200×200
└── temp/                     临时上传（24h 清理）
    └── {date}/
        └── ...
```

### 6.2 图片尺寸规格

| 类型 | 用途 | 尺寸 | 格式 | 质量 |
|------|------|------|------|------|
| original | 原图留存 | 不限制（max 5MB） | jpg/webp | 原始 |
| thumb | 列表卡片/购物车 | 200×260 px | jpg/webp | 80% |
| medium | 详情页展示 | 600×780 px | jpg/webp | 85% |

### 6.3 上传与处理流程

```
1. 前端上传
   - uni-app: uni.chooseImage → uni.uploadFile
   - Vue Web: input[type=file] → FormData

2. 后端接收（API: POST /api/upload）
   - 校验：MIME (image/jpeg, image/png, image/webp)
   - 校验：大小 ≤ 5MB
   - 校验：数量 3-9 张
   - 保存：存入 storage/app/public/temp/{date}/

3. Laravel 处理
   - 使用 Intervention/Image 库
   - 生成 thumb (200×260, fit)
   - 生成 medium (600×780, fit, 仅当宽>600 时)
   - 保存到 storage/app/public/books/{book_id}/
   - 记录到 book_images 表

4. php artisan storage:link
   - 创建 public/storage → storage/app/public 软链接
   - 访问 URL: /storage/books/{book_id}/thumb/xxx.jpg
```

### 6.4 book_images 表写入

| 字段 | 值 |
|------|-----|
| book_id | 书籍 ID |
| path | `books/{book_id}/thumb/cover_1_thumb.jpg` |
| type | cover / inner / spine / other |
| sort | 0-8（排序） |

### 6.5 图片清理策略

| 场景 | 处理 |
|------|------|
| 书籍驳回/下架 | 图片保留（不物理删除） |
| 审核阶段更换图片 | 旧图物理删除 |
| temp 目录 | 计划任务每 24h 清理超过 24h 的文件 |
| 书籍售出 30 天后 | 可清理 original 保留 thumb（可选，后续优化） |
