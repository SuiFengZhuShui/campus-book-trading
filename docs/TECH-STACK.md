# 技术栈

| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 后端框架 | Laravel | 5.8.* | PHP 全栈 MVC 框架 |
| Web 前端 | Vue.js | 2.x | SPA 单页面应用 |
| 移动端 | uni-app | 最新稳定版 | 跨平台（iOS/Android/微信小程序） |
| 数据库 | MySQL | 5.7+ | InnoDB，utf8mb4 |
| 缓存 | Redis | 5.0+ | 可选，会话/队列/缓存 |
| Web 服务器 | Nginx | 1.18+ | 反向代理 + 静态资源 |
| 支付 | 模拟 → 微信/支付宝 | — | 开发阶段模拟，预留真实接口 |

## 环境要求

- PHP >= 7.3
- Composer 2.x
- Node.js >= 14.x + npm
- MySQL 5.7+
